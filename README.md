# turion CLI

[![CI](https://github.com/turion-ai/cli/actions/workflows/ci.yml/badge.svg)](https://github.com/turion-ai/cli/actions/workflows/ci.yml)

This repository hosts the turion CLI for multiple languages, one per folder:

| Folder | Language | Package | Install |
| --- | --- | --- | --- |
| [`node/`](node/) | Node.js | [turion on npm](https://www.npmjs.com/package/turion) | `npm i -g turion` or `npx turion` |

The CLI is currently a placeholder; commands will land in a future release.

## Uninstalling

```bash
npm uninstall -g turion
```
